# ✦ 켈틱 크로스 타로

뒷면으로 펼쳐진 78장 중에서 직접 10장을 골라 **켈틱 크로스** 배열로 풀이하는 웹 타로 게임입니다.
빌드 도구나 이미지 파일 없이 HTML·CSS·JavaScript만으로 동작합니다.

**▶ [플레이하기](https://jeongmin-lee123.github.io/celtic-cross-tarot/)** · **[카드 도감](https://jeongmin-lee123.github.io/celtic-cross-tarot/gallery.html)**

## 주요 기능

- **직접 고르는 카드 뽑기**
  - 섞은 78장을 부채꼴로 펼쳐 둡니다.
  - 고른 카드가 그대로 결과가 됩니다.
  - 고른 카드는 자리로 날아가 뒤집힙니다.
- **78장 오리지널 SVG 아트**
  - 메이저 22장은 카드마다 고유한 장면으로, 마이너 56장은 핍형으로 그렸습니다.
  - 뒷면은 180° 회전 대칭이라, 뒷면만 보고 역방향 카드를 알아챌 수 없습니다.
- **풀이**
  - 10개 포지션별 풀이와 종합 풀이를 보여 줍니다.
  - 질문 주제(전체 운·연애·일·금전)에 따라 종합 풀이가 달라집니다.
- **편의 기능**
  - 놓인 카드를 누르면 크게 보며 정·역방향 의미를 함께 확인할 수 있습니다.
  - 결과를 복사할 수 있습니다.
  - 모바일 화면을 지원합니다.

## 플레이 방법

1. 주제를 고르고 질문을 적습니다. 질문은 비워 둬도 됩니다.
2. **덱 섞고 펼치기**를 누릅니다.
3. 마음이 가는 카드를 1번부터 10번까지 차례로 고릅니다.
4. **종합 풀이 보기**로 전체 흐름을 확인합니다.

덱은 `crypto.getRandomValues` 기반 Fisher–Yates로 섞습니다. 각 카드는 50% 확률로 역방향이 됩니다.

## 켈틱 크로스 배열

가장 널리 쓰이는 현대식 배열을 따릅니다. 1~6번 크로스는 상황 자체를, 7~10번 스태프는 상황을 둘러싼 나와 주변을 봅니다.

| # | 포지션 | 의미 | 위치 |
|---|---|---|---|
| 1 | 현재 상황 | 질문의 중심에 놓인 상황 | 가운데 |
| 2 | 도전·장애 | 지금 마주한 과제나 방해 요인 | 1번 위에 가로로 |
| 3 | 과거·근원 | 지금을 만든 과거의 뿌리 | 왼쪽 |
| 4 | 가까운 미래 | 앞으로 몇 주~몇 달의 흐름 | 오른쪽 |
| 5 | 의식·목표 | 의식적으로 바라는 것 | 위 |
| 6 | 무의식·내면 | 드러나지 않은 속마음 | 아래 |
| 7 | 나의 태도 | 이 문제를 대하는 자세 | 스태프 맨 아래 |
| 8 | 주변 환경 | 주위 사람과 환경의 영향 | |
| 9 | 희망과 두려움 | 바라면서도 걱정하는 것 | |
| 10 | 최종 결과 | 지금 흐름이 이어질 때의 결과 | 스태프 맨 위 |

출처마다 3~6번의 순서가 조금씩 다릅니다.

### 종합 풀이가 보는 것

- **전체 기운**: 정방향과 역방향 카드의 비율
- **핵심 구도**: 1번(현재)과 2번(도전)
- **시간의 흐름**: 3번(과거) → 1번(현재) → 4번(가까운 미래)
- **겉마음과 속마음**: 5번(의식)과 6번(무의식)이 같은 방향인지
- **카드 구성**:
  - 메이저 카드의 비중으로 흐름의 크기를 봅니다.
  - 가장 많이 나온 수트로 주제를 짚습니다: 완드=일·열정, 컵=감정·관계, 소드=생각·갈등, 펜타클=돈·현실.
- **주제**: 고른 주제와 맞닿은 수트가 몇 장, 어느 자리에 나왔는지
- **결론과 조언**: 10번(결과)과 7번(태도)

## 카드 아트

모든 카드는 `js/art.js`에서 SVG 도형을 조합해 직접 그렸습니다.
그리기 전에 상용 덱 24종의 레이아웃과 도상 관례를 조사했고, 특정 덱의 구도나 고유 요소는 따라 그리지 않았습니다.
조사 내용은 [research/deck_design_reference.md](research/deck_design_reference.md)에 있습니다.

- **앞면**: 위에 로마숫자, 가운데 그림, 아래에 이름 배너를 둡니다. 수트마다 고유 색을 씁니다.
- **마이너**: 수트 상징을 숫자만큼 배치합니다. 에이스는 큰 상징 하나, 코트 카드는 인물과 상징으로 그리고, 나이트는 말을 탑니다.
- **뒷면**: 남색 격자 위에 8각 별과 초승달을 180° 회전 대칭으로 배치했습니다.

카드 의미는 라이더-웨이트 계열의 일반적인 해석을 바탕으로 직접 작성했습니다.

## 로컬 실행과 테스트

`index.html`을 브라우저로 바로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
python -m http.server 8000      # http://localhost:8000
node tests/reading.test.js      # 덱·셔플·풀이·아트 생성 테스트
```

## 구조

```
index.html          게임 화면
gallery.html        카드 도감
css/style.css       스타일과 애니메이션
js/cards.js         78장 카드 데이터
js/art.js           카드 앞·뒷면 SVG 아트
js/reading.js       포지션 정의, 셔플, 풀이 문장 생성
js/app.js           게임 진행과 UI
tests/              로직·아트 테스트
research/           사업 기획 리서치 (시장조사, 벤치마크 수집 스크립트, 카드 디자인 조사)
```

`research/`의 벤치마크 수집 원문은 타 사이트의 저작물이라 저장소에 포함하지 않습니다. 분석 스크립트만 공유합니다.
