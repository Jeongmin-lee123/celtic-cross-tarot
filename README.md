# 켈틱 크로스 타로

78장 타로 덱에서 10장을 순서대로 무작위로 뽑아 **켈틱 크로스** 배열로 풀이해 주는 웹 게임입니다.
빌드 도구 없이 정적 파일만으로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
python -m http.server 8000   # http://localhost:8000
```

## 플레이 방법

1. 주제(전체 운·연애·일·금전)를 고르고, 질문을 떠올린 뒤(입력은 선택) **덱 섞고 펼치기**를 누릅니다.
2. 뒷면으로 펼쳐진 78장 중에서 마음이 가는 카드를 **직접 골라** 1번부터 10번까지 채웁니다.
   - 덱은 `crypto.getRandomValues` 기반 Fisher–Yates로 섞습니다.
   - 각 카드는 50% 확률로 역방향이 됩니다.
   - 고른 카드가 실제 결과가 됩니다.
3. 카드가 자리로 날아가 뒤집히면, 포지션별 풀이가 쌓입니다. 놓인 카드를 누르면 크게 보며 정·역방향 의미를 확인할 수 있습니다.
4. 10장을 모두 고르면 **종합 풀이**를 보고, 결과를 복사할 수 있습니다.

`gallery.html`(카드 도감)에서 78장 전체와 뒷면을 볼 수 있습니다.

## 카드 아트

앞·뒷면은 모두 `js/art.js`에서 SVG 도형을 조합해 직접 그렸습니다. 이미지 파일은 쓰지 않습니다.

- 그리기 전에 상용 덱 24종의 레이아웃·도상 관례를 조사했습니다: [research/deck_design_reference.md](research/deck_design_reference.md)
- 앞면 구성: 위쪽 로마숫자, 가운데 그림, 아래쪽 이름 배너. 수트마다 고유 색을 씁니다.
- 마이너 카드는 핍형입니다. 수트 상징을 숫자만큼 배치하고, 에이스는 큰 상징으로, 코트 카드는 인물과 상징으로 그립니다.
- 뒷면은 180° 회전 대칭이라, 뒷면만 보고 역방향 카드를 알아챌 수 없습니다.

## 켈틱 크로스 배열 (현대 표준형)

| # | 포지션 | 의미 |
|---|---|---|
| 1 | 현재 상황 | 질문의 중심에 놓인 상황 |
| 2 | 도전·장애 | 1번 위에 가로로 겹치는 카드. 과제나 방해 요인 |
| 3 | 과거·근원 | 지금을 만든 과거의 뿌리 (왼쪽) |
| 4 | 가까운 미래 | 앞으로 몇 주~몇 달의 흐름 (오른쪽) |
| 5 | 의식·목표 | 의식적으로 바라는 것 (위) |
| 6 | 무의식·내면 | 드러나지 않은 속마음 (아래) |
| 7 | 나의 태도 | 이 문제를 대하는 자세. 스태프 맨 아래 |
| 8 | 주변 환경 | 주위 사람과 환경의 영향 |
| 9 | 희망과 두려움 | 바라면서도 걱정하는 것 |
| 10 | 최종 결과 | 지금 흐름이 이어질 때의 결과. 스태프 맨 위 |

1~6번은 크로스로 상황 자체를 보고, 7~10번은 스태프로 상황을 둘러싼 나와 주변을 봅니다.
포지션 순서는 출처마다 조금씩 다르며(특히 3~6번), 이 게임은 가장 널리 쓰이는 현대식 배열을 따릅니다.

## 종합 풀이 규칙

종합 풀이는 다음 항목을 차례로 짚습니다.

- **핵심 구도**: 1번(현재)과 2번(도전)의 관계
- **시간의 흐름**: 3번(과거) → 1번(현재) → 4번(가까운 미래)
- **겉마음과 속마음**: 5번(의식)과 6번(무의식)의 방향이 같은지
- **카드 구성**:
  - 메이저 카드가 4장 이상이면 큰 흐름이 작용한다고 봅니다.
  - 1장 이하이면 일상의 선택으로 바꿀 수 있는 문제로 봅니다.
  - 가장 많이 나온 수트로 주제를 짚습니다: 완드=일·열정, 컵=감정·관계, 소드=생각·갈등, 펜타클=돈·현실.
- **전체 기운**: 정방향과 역방향 카드의 비율
- **결론과 조언**: 10번(결과)과 7번(태도)

```
js/cards.js         78장 카드 데이터 (의미는 일반적 해석을 바탕으로 직접 작성)
js/art.js           카드 앞·뒷면 SVG 아트
js/reading.js       포지션 정의, 셔플·드로우, 풀이 문장 생성
js/app.js           게임 진행과 UI
tests/              node tests/reading.test.js
research/           사업계획 리서치 (수집 스크립트, 시장조사)
```

## 참고

- 카드 의미는 라이더-웨이트 계열의 널리 알려진 해석을 바탕으로 새로 작성했습니다.
- `research/`의 크롤링 원문 데이터는 저작권 때문에 저장소에 포함하지 않습니다.
- 오락용 콘텐츠입니다.
